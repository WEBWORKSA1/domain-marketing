Tools for selling a domain

Each tool answers one question a seller actually has. They run in your browser, show their working, and label estimates as estimates.

Which tool first?

If you have one name to sell, start with the plan builder: it uses the scorecard and the venue table to give you a price mode, a short list of venues and a thirty-day schedule. If you hold a portfolio, start with the portfolio calculator and find your floor price before you spend time on any single name.

How the numbers are made

Fees come from each company’s published pages and carry a read date. Scores and price bands come from fixed rules that are listed on the tool’s own page. Nothing here uses private sales data, and nothing replaces checking real comparable sales before you fix a price.
