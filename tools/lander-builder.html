Build a for-sale page for your domain

Fill in the form and watch the page take shape. When it looks right, download a single HTML file and upload it to any web host. No account, no code to write.

Putting the page online

  1. Download the file. It is called index.html and contains everything: no images, fonts or scripts to host.
  2. Upload it to any static host. Most registrars include basic hosting or forwarding, and several free hosts will serve a single page with HTTPS.
  3. Point the domain at that host using the DNS records it gives you.
  4. Open the name on your phone, press the button, and confirm the message reaches you.

What the page includes, and why

The name as a headline, a single line on who it suits, the price or offer route, one button, up to four selling points and two sentences explaining escrow. That is everything a visitor needs to act and nothing that slows the page down. The reasoning is in the for-sale page playbook.

If you put an email address on the page, use one you are happy to see in public, since anyone who views the page can read it. A web address for a contact form or a marketplace listing keeps your inbox private.

Questions people ask

Do I need an account to use the page?

No. The file is yours. It contains no tracking and no link back to this site.

Can I edit the page afterwards?

Yes. It is plain HTML with the styles inline at the top. Any text editor will open it.

How do I take payment?

The page starts the conversation. Close the sale through a licensed escrow service or a marketplace checkout so that neither side has to trust the other with the money.
